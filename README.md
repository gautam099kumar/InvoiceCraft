# InvoiceCraft

B2B Invoice and Accounts Receivable Management SaaS.

## Project Overview

InvoiceCraft is a business application designed to help organizations manage customers, create and issue invoices, record payments, and track outstanding receivables.

## Core Features

- Organization and user management
- Customer management
- Product and service catalog
- Invoice creation and management
- Payment tracking
- Accounts receivable management
- Role-based access control

## Technology Stack

- Java 21
- Spring Boot
- Spring Data JPA
- Spring Security
- MySQL
- React

## Architecture

InvoiceCraft will initially be developed as a modular monolith.

## Project Status

Development environment setup and repository initialization completed.

The application is currently in the initial development phase.
